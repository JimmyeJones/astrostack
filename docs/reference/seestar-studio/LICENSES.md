# Third-party material

## 3D model of the telescope
`model_src/Seestar_S30_Pro.obj` and `seestar_model.json` (derived from it by `model_src/convert_model.py`)
are "Seestar S30 Pro - Telescope" by **WistowTbone**, https://www.thingiverse.com/thing:7342818,
licensed **Creative Commons Attribution-ShareAlike (CC BY-SA)**. Keep this attribution and the same
licence if you redistribute or adapt the model. It is the author's own measurement of an S30 Pro,
not ZWO data.

## Protocol knowledge
Command shapes were cross-checked against seestarpy (astronomyk/seestarpy), seestar_alp
(smart-underworld/seestar_alp) and seestar-spec (zmerlynn/seestar-spec). No code from those
projects is included.

Seestar is a product of ZWO; this project is unofficial and not affiliated with ZWO.
