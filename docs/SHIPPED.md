# Shipped — the record

The archive [`IMPROVEMENTS.md`](IMPROVEMENTS.md) cuts to, so the backlog stays a
**working list**. When an item ships or is closed, cut the whole entry from
`IMPROVEMENTS.md` and append it here as one block, headed by its version and
date; leave a one-line `✅ v0.xxx.y <what>` under "Shipped" in the backlog.

Nothing here is open work — an entry in this file has already happened. **Grep it
before filing an idea**: the backlog has repeatedly carried items that shipped
months earlier, and a shipped entry sitting inside a priority section is
indistinguishable from live work by every triage method an agent uses.

Newest first.
